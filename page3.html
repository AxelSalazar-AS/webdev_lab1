My Future Career in Technology

A look at my interest in information technology and cloud computing.

Why I Chose Technology

Technology interests me because there are always new things to learn. Computers are used in almost every industry, which creates many different career opportunities. Studying Information Technology and Management allows me to learn both technical and professional skills.

Through my classes, I have been able to learn more about programming, computer hardware, operating systems, databases, and web development. These subjects have helped me understand the different areas of the technology industry and decide which areas I want to explore further.

Cloud Computing

One area that interests me is cloud computing. Cloud computing allows people and organizations to access computing resources over the internet instead of depending entirely on computers and servers that are physically located in one place.

Cloud technology is used for many different purposes, including storing data, running applications, hosting websites, managing databases, and providing computing resources to businesses. Learning about cloud computing can also involve networking, operating systems, cybersecurity, databases, and programming.

Skills I Want to Develop

There are several technical skills that I want to continue developing throughout college. Programming is important because it helps me understand how software works and how problems can be solved using computers.

  • Cloud computing
  • Linux
  • Computer networking
  • Python programming
  • Java programming
  • SQL and databases
  • Cybersecurity
  • Web development

I also want to improve professional skills such as communication, teamwork, leadership, and problem solving. Technical knowledge is important, but being able to communicate and work with other people is also important in a professional technology environment.

My Future Goals

My goal is to continue gaining experience while completing my degree at Illinois Institute of Technology. I want to participate in internships and projects that allow me to work with technology in a professional environment.
